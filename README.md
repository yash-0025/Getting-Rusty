# 🦀 Rust Mastery - 30-Day Intensive Journey

Welcome to the Rust Mastery workspace! This repository documents a structured, 30-day intensive journey to go from a Full-Stack/Web3 engineer to a production-grade Rust developer capable of writing highly concurrent, memory-safe backend systems.

## 🎯 The Approach

This curriculum follows a **strictly project-based** philosophy:
> *"Every day starts with 'Build ___'. Concepts are taught just-in-time because the project demands them. You never learn a concept in a vacuum."*

Instead of reading textbooks, we build real things:
* **Week 1:** CLI Tools (Unit Converter, Duplicate File Finder, Task Tracker, Text Analytics).
* **Week 2:** Libraries & Generics (Generic Stacks/Queues, Trait Objects, Lifetimes, AST Evaluators, and a Generic In-Memory Cache).
* **Week 3:** Concurrency & Async (Parallel Word Counters, Async Web Scrapers, Axum REST APIs).
* **Week 4:** Advanced Patterns & Production Capstone.

## 📜 The Governance System

This workspace is managed strictly according to rules defined in `RULES.md`. An AI tutor guides the learning process but must adhere to the following core constraints:

1. **No Silent Edits:** The AI cannot modify the roadmap or learning logs without explicit permission.
2. **Every Change is Logged:** Every modification to the workspace is recorded in `LOGS.md`.
3. **Source of Truth:** `LEARNING.md` is the living journal of actual progress. `ROADMAP.md` is the curriculum.
4. **No Copy-Pasting:** The AI must explain *what*, *how*, and *why* before providing code, forcing the learner to type and internalize the syntax.
5. **Extreme Syntax Explanations:** Every line of code, keyword, and symbol must be exhaustively broken down (Rule 11).
6. **Dual-Track Explanations:** Every new concept gets both a simple ELI5 analogy and a rigorous technical explanation, stored permanently in `EXAMPLES.md`.

## 📁 Repository Structure

* `ROADMAP.md`: The planned 30-day curriculum and deliverables.
* `LEARNING.md`: The daily diary of concepts mastered, mistakes made, and project status.
* `RULES.md`: The strict governance rules for the AI tutor and the learning process.
* `LOGS.md`: The audit trail of every modification made to the workspace.
* `EXAMPLES.md`: A growing encyclopedia of ELI5 analogies and technical breakdowns for Rust concepts.
* `Notes.md`: The learner's personal handwritten study notes.
* **Project Folders:** E.g., `hello-rust`, `capstone-tracker`, `in_memory_cache`, `parallel_word_counter`, etc.
